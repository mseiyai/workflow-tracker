# Product requirements

User: the owner of a small stationery business.

Problem: customer work is scattered across notebooks and messages.

A task has:
- id: a unique integer
- title: a short description
- status: pending, in_progress, or done

First milestone:
Read example tasks from data/tasks.json and print status counts.

Later milestones:
Browser interface, API, database, testing, containers, and deployment.
